# SWINGS

골프 관심사를 기반으로 사람을 연결하는 소셜 매칭 플랫폼입니다.  
피드, 1:1 소개팅, 그룹 매칭, 실시간 채팅, 알림 기능을 하나의 서비스 흐름으로 구성했습니다.

## 프로젝트 개요

- 기간: 2025년 3월 ~ 2025년 4월
- 형태: 팀 프로젝트
- 목적: 골프라는 공통 관심사를 중심으로 자연스러운 만남과 커뮤니티 경험을 제공하는 서비스 구현
- 특징: 모바일 사용성을 중심에 두되, 웹에서도 시연 가능한 구조로 설계

## 핵심 기능

- 소개팅 매칭
  - 추천 프로필 확인
  - 호감 보내기
  - 슈퍼챗으로 즉시 대화 시작

- 피드
  - 게시글 작성, 수정, 삭제
  - 댓글 및 좋아요
  - 소셜 프로필 확인

- 모임
  - 필드/스크린 그룹 생성
  - 참가 요청 및 승인
  - 대기자 관리

- 채팅 및 알림
  - 1:1 채팅
  - 실시간 메시지 반영
  - 알림 목록 및 읽음 처리

## 기술 스택

### Frontend

- React 18
- Vite
- React Router
- Tailwind CSS
- Framer Motion
- Axios
- Firebase
- SockJS / STOMP

### Backend

- Java 17
- Spring Boot 3
- Spring Security
- Spring Data JPA
- WebSocket
- Redis
- MySQL
- Firebase Admin SDK

## 프로젝트 구조

```text
SWINGS/
├─ SWINGS-FE/   # React + Vite 프론트엔드
├─ SWINGS-BE/   # Spring Boot 백엔드

```

## 실행 방법

### Frontend

```bash
cd SWINGS-FE
npm install
npm run dev
```

### Backend

```bash
cd SWINGS-BE
./gradlew bootRun
```

로컬 실행 시 환경 변수와 Firebase 설정 파일, DB 연결 정보가 필요합니다.

## 포트폴리오 포인트

- 단순 CRUD가 아니라 매칭, 피드, 채팅, 그룹 기능을 하나의 서비스 흐름으로 연결
- 모바일 중심 UI를 웹 시연 환경까지 고려해 리팩토링
- 실시간 채팅과 알림, 그룹 참가 흐름까지 포함한 사용자 경험 설계
- 배포 전 포트폴리오 시연용 더미 데이터와 문구를 자연스럽게 정리

## 배포 전 체크 포인트

- 프론트 빌드 확인
  - `npm run build`
- 백엔드 빌드 확인
  - `./gradlew build`
- 환경 변수와 API 주소 점검
- Firebase, 알림, OAuth 설정값 확인
